#### 修复实现细节

**Open redirect** —— 抽出 `frontend/src/utils/safe-redirect.js`：仅放行单 `/` 开头的相对路径；`//` / `https://` / `javascript:` / `data:` / 任何 `scheme:` 一律 fallback `/chat`。LoginView 改为 `router.push(safeRedirect(route.query.redirect))`。

**picture_url** —— 在 `routes/auth.py` 加 `_safe_picture_url(value)`：仅放行 `https://` 字符串；其他（None / `javascript:` / `data:` / `http://` / 非字符串）→ None。`_user_response` 和 `/api/auth/invite/<token>` 的 `user.picture_url` + `inviter.picture_url` 都过这个函数。前端继续直接 `<img :src>`，单一信任源在后端。

**is_token_valid** —— 加 `_parse_iso(s)` 严格解析 `%Y-%m-%dT%H:%M:%SZ` 为 tz-aware datetime；非该格式抛 `ValueError`（loud failure 优于 silent miscompare）。比较改为 datetime vs `datetime.now(timezone.utc)`。
