# Dev Log — 2026-05-26

## 1. multi-user-auth-admin-ui

**Commit:** `f78d9cd`

**Features:**

- `@require_admin` Flask middleware: 401 (unauthenticated) vs 403 (non-admin), re-validates session from DB on every request
- 5 admin REST endpoints under `/api/admin/users`: list, invite, patch, delete, resend-invite
- `delete_user_cascading` service: Qdrant filter-delete runs before SQLite cascade so partial failures leave recoverable state (user row intact, Qdrant already clean)
- `useAdminUsersStore` Pinia store with injected axios for testability
- `InviteUserModal.vue`: invite form + 3 conflict states (existing active/invited/disabled user, each with different CTA)
- `DeleteUserModal.vue`: type-to-confirm gate (must type email local-part to unlock red delete button)
- `AdminUsersView.vue`: desktop CSS-grid 6-column table + mobile card list; self-row shows "不能改自己" with no action buttons; only-admin guard disables demote button
- AppLayout: conditional 5th sidebar nav item visible only to admins
- Router: `/admin/users` with `meta.requiresAdmin: true` guard; member → `/chat`, unauthenticated → `/login?redirect=…`
- Playwright E2E: invite+accept (separate browser context), PATCH disable/re-enable, DELETE with type-to-confirm gate
- CLAUDE.md updated: `/admin/users` is primary path; CLI (`python -m app.cli.invite_user`) is emergency fallback
