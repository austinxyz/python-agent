3. 用户接受邀请的流程

从收到链接 → 设密码激活 → 第一次登录。Admin 不参与，用户独立完成。

1. Admin 在 /admin/users 邀请 → 复制 invite URL → 通过带外渠道（微信/短信/WhatsApp）发给用户
2. 用户点链接 → 浏览器打开 http://10.0.0.20:8910/accept-invite?token=abc123...
3. 页面验证 token → 设密码表单（HTTPS/localhost 上还有 "或用 Google 登录" 选项）
4. 提交 → token 标记 used + 用户 status='active' + Flask session 创建 → 跳 /chat
5. 之后正常 邮箱+密码 在 /login 登录

系统不发邮件：邀请通过 admin 复制 + 带外渠道发出。家用规模够用，省 SMTP 配置。
用户看到邀请人：banner 显示 "Austin 邀请你" + admin 头像——建立信任。

激活后直接登录：POST 成功直接 set session 跳 /chat。
三个错误状态都给清晰出路：过期 → 找 admin / 已用 → 去 /login / 无效 → 检查链接。

4. 修改密码（ChangePasswordView）

用户从 user pill 菜单 / Mobile "我" tab 进入。简单 3 字段表单。

/change-password — 主区域居中卡片
修改密码

改完密码会立即生效。其他设备上正在使用的会话会被踢下线（session_version 升级）。

至少 8 字符。建议混合字母+数字。
