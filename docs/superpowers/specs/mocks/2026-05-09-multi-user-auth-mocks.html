行为细节
路由守卫： 未登录 + 访问 /chat /wiki /ingest /private → 自动跳 /login（保留 redirect=...）
默认登录后落点： /chat（不是当前的 /wiki）
未登录状态 sidebar nav： 灰色显示，点击触发 router guard 跳 /login
已登录退出： 点 ⏻ 按钮 → 调 /api/auth/logout → 跳 /login
Mobile 不复用 sidebar 模式： 已登录用 bottom-tab，未登录 /login 全屏。这是因为 mobile 屏窄；growing 是 web-only 没这个约束。
